## 4. 视觉与交互规范核对

- 默认主题 `landscape`，白色基底、森林绿主色、墨绿灰文字、半透明白色卡片、层叠阴影。
- 基础正文 16px/1.75；主标题 40–44px，分组标题 21px，卡片摘要约 13px。
- 主按钮至少 40px，紧凑控制至少 36px；交互须具有可见焦点和禁用状态。
- 桌面侧栏 + 内容区；960px 以下转换为顶部目录；760px 以下摄影展示变为轮播在上、主题列表在下。
- 二级抽屉保留原页面，三级查看器关闭后回到原抽屉；摄影与项目共用查看器底层组件。
- 摄影自动切换间隔 6 秒，仅在当前页面、标签可见且没有用户交互、悬停或减少动态效果时启动。
- 图片不得虚构；原始作品、PDF 和图片文字不会被界面语言切换自动翻译。
- 首页动画以 SVG+CSS 实现，不依赖视频、Three.js 或外部 CDN；文字立即可读，装饰不遮挡正文。

## 5. 测试结果的证据等级

**代码检查：** 由 `scripts/check.mjs` 校验 JS 语法、数据引用、翻译覆盖、五页导航、空素材路径、主题注册、动效规则和既有模块回归。是否实际运行成功，应由 CI 或本地 Node 20+ 的执行结果确认。

**待浏览器手工验收：**
- 1440px 桌面：五页导航、摄影左右结构、标题换行、抽屉/查看器叠层。
- 820px 平板：顶部目录、页面可读性、阅读容器宽度。
- 390px 手机：摄影轮播在前、主题列表在后、左右手势、按钮触控、无横向溢出。
- 中英切换：当前页面不跳转；抽屉/查看器保留打开状态和内容位置。
- 首页动画：会话首次进入播放；重新进入首页不播放；减少动态效果使用静态终态。
- 上传真实摄影作品后：图片加载、比例、alt 文本、前后切换、缩略图、原图隐私信息。
