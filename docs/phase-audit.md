## 一、产品需求与当前实现的差异

### 原始 PRD V7 定义

Notion《Project Nebula · 展示版 PRD》将产品定义为可探索、可交互、可对话的个人 AI 展示站，包含：

1. 第一层：首屏引导页，建立品牌气质与进入仪式感，并在点击或停留 5 秒后转场。
2. 第二层：能力星球总览，以中心恒星和四颗行星呈现能力系统，支持非线性导航、悬停说明和已访问状态。
3. 第三层：五个独立内容区，分别承载 AI 奇点、星工场、造物星、聚变星、脉冲星。
4. 全局 Agent：跨页面悬浮，支持快捷问题与自由输入。
5. 详情页：返回星球总览、上一站/下一站和联络中枢等连续探索入口。

## 三、视觉系统审查

### 色彩

当前语义色值：

| 用途 | 色值 | 白底对比度 |
| --- | --- | ---: |
| 正文墨绿灰 | #26342D | 13.03:1 |
| 辅助文字苔灰 | #66746C | 4.91:1 |
| 主色森林绿 | #285C43 | 7.77:1 |
| 辅助植被绿 | #4F755D | 5.20:1 |
| 装饰雾绿 | #B9CCBE | 不用于正文 |

**判断：** 正文、辅助文字与主要按钮文字对比度达到常见 WCAG AA 文本要求；装饰色不应被用于小字号文字。本次已将真实色块、用途和对比度补进当前设计规范页。

### 字体与文字层级

- 正文基准：16px，行高 1.75。
- Display：40–44px；H1：28–34px；H2：23–26px；H3：21px。
- 次级说明：14px；caption：12px；eyebrow：约 11px。
- 中文使用系统无衬线字体栈；代码与编号使用等宽字体回退栈，不加载外部字体服务。

**判断：** 字号层级总体成立。个人奇点中的技能说明、卡片 metadata 和标签仍有 10–12px 的小字，只适合辅助信息，不应继续扩展成长段正文。当前系统没有真实加载 Noto/IBM 字体文件，不同设备会回退到本机字体，设计规范已明确这一点。

### 按钮与组件

本次统一了共享控件尺寸 token：

- 主要按钮：40px。
- 图标按钮：40×40px。
- 紧凑媒体/语言控件：36px。
- 能力证据入口：最小高度 44px。
- 焦点：统一 2px 可见描边；禁用态降低透明度。
- 媒体 Tab：增加左右方向键、Home、End 键盘切换和 roving tabindex。

**判断：** 主次按钮与卡片语言已比较一致；辅助文本链接仍属于轻量操作，不应替代关键 CTA。触控尺寸是否足够仍需真实手机检查。

### 页面布局

- 桌面侧栏：264px。
- 主内容最大宽度：1200px。
- 详情抽屉：最大 760px。
- 第三级查看器：最大 1120px。
- 断点：1100 / 960 / 760 / 560 / 380px。

**判断：** 桌面采用固定目录和受限正文宽度，阅读路径清晰；760px 以下转单列合理。项目卡片和能力卡片仍需要在 390px 与 820px 实机/浏览器宽度检查长标题、状态文本和按钮换行。
