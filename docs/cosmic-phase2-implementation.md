# 个人作品站 · Phase 2 神秘宇宙与全局布局修缮

> 依据：用户已确认《四主题统一视觉系统与主题切换架构 V2.0》。第一套景观白绿已合并至 main（8aa9995170bf237f69f1ebd4cdcb5eae49e44e41），本次增量仅在独立分支中。
>
> 范围：一套新的可切换主题 + 联系区减重 + 左侧内容导航可折叠。

## 1. 本期设计决策

- **神秘宇宙 Mystical Cosmic**：浅灰/暖灰页面底色，古金、香槟金、红调金褐。不是黑色星空背景。
- **Typography**：中文标题首选 Source Han Serif SC，中文正文 Source Han Sans SC；英文标题 Cormorant Garamond，英文正文 Inter。英文衬线字体可按需通过 Google Fonts 加载，加载失败自动回退 Georgia；中文字体尊重设备可用字体并提供系统回退。
- **Cards**：外框深金褐 + 内框香槟金的双层描边默认可见；阴影轻，悬停边线增强和一次短暂微光，不复用景观主题的小圆角建筑抬升感。
- **Motif**：仅首页使用星盘、轨迹、星座连接线与少量微光；其余内容页只保留克制的几何星点。
- **Motion**：局部星轨约 30s 低速旋转，小范围星光 4.5s 明暗变化；减少动态效果时完全静态。
- **ThemePicker**：景观白绿 / 神秘宇宙可切换；小王子 / 冷调烟紫仍 Planned，未完成不开放。
- **联系人页尾**：仍在五个内容页最下方，标题 16–19px，信息 12px，减少留白和视觉抢占。
- **桌面侧栏**：左栏顶部折叠按钮，展开 264px、折叠 60px；折叠状态持久化且可再展开；手机仍使用顶部 Menu，不额外引入第二套移动菜单。

## 2. 技术实现边界

- 共用 HTML 页面、语言索引、Search、项目/文章/文档抽屉、摄影轮播及媒体 Viewer。不克隆网站，不迁移真实内容。
- 宇宙独立样式文件：`assets/css/themes/cosmic.css`，所有主题变量由 `data-theme` 控制。
- 场景插画使用轻量 SVG，定义于原首页 hero 中；景观插画和宇宙插画互斥显示。
- 各页面页尾只调整 CSS，联系方式与原文本不删除。
- 折叠状态由 `project-nebula-sidebar-collapsed` 维护，中英文 aria-label 同步更新。
- `main` 与历史回滚分支不作增量修改；新功能通过本期分支 PR 验收后再决定发布。
